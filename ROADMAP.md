# Public roadmap

Everstack is pre-1.0. The roadmap communicates direction, not guaranteed dates
or compatibility promises.

## Now

- Reproducible Community Edition builds and releases
- A reliable five-minute local quickstart
- Agent, sandbox, browser, and workflow lifecycle hardening
- Clear Community, Cloud, and Enterprise boundaries
- Documentation and examples that are continuously tested

## Next

- Reproducible gateway and sandbox performance benchmarks
- More end-to-end agent templates and integration examples
- SDK consistency across Go, TypeScript, and Python
- Contributor-friendly extension points for providers, tools, and backends
- Better upgrade, backup, and operational runbooks

## Later

- Broader deployment automation and regional topologies
- More policy, evaluation, and governance primitives
- Additional sandbox and memory backends driven by real deployments

Track concrete work in [GitHub Issues](https://github.com/everstacklabs/everstack/issues)
and propose priorities in
[GitHub Discussions](https://github.com/everstacklabs/everstack/discussions).
