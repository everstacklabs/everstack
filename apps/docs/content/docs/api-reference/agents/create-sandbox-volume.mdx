### Request Body

| Property | Type | Required | Description |
|----------|------|----------|-------------|
| `name` | `string` | No |  |
| `tenantId` | `string` | No | Optional; defaults to the caller's tenant resolved from context. |
| `sizeGb` | `string` | No | Optional capacity quota in GiB (0 = unlimited). Volumes are usage-billed regardless of quota; this only caps how large the volume may grow. |


### Responses

#### 200 Create a persistent volume

| Property | Type | Description |
|----------|------|-------------|
| `volume` | `object` | Persistent sandbox volume (POR-77). Object-storage-backed; usage-metered. |
