|------|-----|------|----------|-------------|

### Request Body

| Property | Type | Required | Description |
|----------|------|----------|-------------|
| `path` | `string` | No | File path the op targets (required for diagnostics/symbols). |
| `query` | `string` | No | Query string (workspace-symbols). |
