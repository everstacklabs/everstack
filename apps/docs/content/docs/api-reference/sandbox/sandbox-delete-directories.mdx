### Description
Deletes one or more directories from the sandbox filesystem, including all of their contents recursively (equivalent to `rm -rf`). Paths that do not exist are silently ignored.

### Path Parameters
| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `sandbox_id` | `string` | Yes | Sandbox ID or name |

### Request Body
| Property | Type | Required | Description |
|----------|------|----------|-------------|
| `paths` | `string[]` | Yes | List of absolute directory paths to delete inside the sandbox |

### Responses
#### 200 Success
| Property | Type | Description |
|----------|------|-------------|
| `status` | `string` | Always `"deleted"` on success |

#### default An unexpected error response.
| Property | Type | Description |
|----------|------|-------------|
| `code` | `integer` | |
| `message` | `string` | |
| `details` | `object[]` | |
