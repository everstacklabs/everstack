# The named groups below are redundant with "User-agent: *" by the letter of
# the spec. They are not redundant in practice: several AI crawlers were
# measured taking a 403 at the edge on everstack.ai in August 2026, which
# leaves their operators no on-site signal about intent. Naming each agent
# states the intent plainly. A crawler obeys the most specific group that
# matches it and ignores "*" entirely, so each group is self-contained.
#
